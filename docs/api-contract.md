# EduTask API contract

Этот документ фиксирует минимальный обмен данными между интерфейсом и Backend.

## Создание черновика

`POST /api/tasks/draft`

```json
{
  "rawDescription": "Мне нужен интерактивный урок истории Казахстана для 8 класса"
}
```

Ответ:

```json
{
  "id": "task-demo-001",
  "status": "draft",
  "rawDescription": "...",
  "questions": [
    "Для какого уровня подготовки нужны материалы?",
    "Какой формат интерактивности предпочтителен?",
    "Какие ограничения по времени и платформе нужно учесть?"
  ]
}
```

## Генерация карточки

`POST /api/tasks/:id/generate-card`

Тело запроса содержит ответы преподавателя:

```json
{
  "answers": {
    "users": ["Ученики 8 класса"],
    "subject": "История Казахстана",
    "format": "Интерактивный урок",
    "materials": "Учебная программа и материалы урока",
    "constraints": ["45 минут", "онлайн"],
    "deadline": "До 2 недель"
  }
}
```

Ответом является объект из [`task-schema.json`](../api/task-schema.json).

## Каталог

`GET /api/tasks`

Возвращает только опубликованные задачи. Поддерживаемые параметры на MVP:

- `subject` — фильтр по предмету;
- `level` — фильтр по уровню готовности;
- `sort=score` — сортировка по рейтингу.

## Предложение команды

`POST /api/tasks/:id/proposals`

```json
{
  "teamName": "History Lab",
  "idea": "Сделаем интерактивный квест с картой событий",
  "plan": "Сценарий, прототип, тестирование",
  "deadline": "10 дней",
  "link": "https://example.com/demo"
}
```

Финальный выбор команды всегда выполняется вручную преподавателем через:

`PATCH /api/tasks/:id/proposals/:proposalId`

```json
{
  "decision": "accepted"
}
```
