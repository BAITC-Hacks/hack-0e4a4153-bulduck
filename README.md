# EduTask — MVP для AI Sana

Интерактивный прототип платформы, которая превращает сырое описание педагогической потребности в структурированную задачу для студенческих команд.

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не нужны для локальной демо-версии.

Если вы хотите включить реальный AI-вызов (OpenAI), можно запустить небольшой локальный сервер, который проксирует запросы к API OpenAI.

1) Создайте файл `.env` (или экспортируйте переменную окружения) с ключом:

```
OPENAI_API_KEY=ваш_ключ
```

2) Установите зависимости и запустите сервер:

```bash
npm install
node server.js
# сервер слушает на http://localhost:3000
```

3) Откройте `index.html` в браузере и на шаге 2 нажмите "Продолжить" — фронтенд попытается вызвать `POST /api/generate` и получить поля карточки от сервера.

## Сквозной сценарий

1. Преподаватель вводит краткое описание задачи.
2. Интерфейс показывает уточняющие поля.
3. Система формирует редактируемую карточку задачи.
4. Задача публикуется в каталоге.

AI-функция сейчас представлена локальным демо-контрактом в `app.js`. В проект добавлен `server.js`: если задана переменная `OPENAI_API_KEY`, сервер будет проксировать запрос к OpenAI, иначе вернёт детерминированную заглушку.
