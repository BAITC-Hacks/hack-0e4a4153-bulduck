# EduTask

MVP для AI Sana: преподаватель уточняет потребность с AI, подтверждает карточку, публикует задачу, получает предложения студенческих команд и вручную принимает или отклоняет их.

## Запуск

Нужен Node.js 18+ с fetch (проверено на Node.js 24). Устанавливать зависимости не требуется.

```powershell
npm.cmd start
```

Откройте http://localhost:3000. Проверка сервера: http://localhost:3000/api/health.
Открытие index.html через file:// не поддерживается для работы с общим каталогом.
Остановить сервер: Ctrl+C. После изменения .env перезапустите его.

Если .env отсутствует, создайте его по .env.example. Не перезаписывайте уже настроенный файл.

```env
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini
PORT=3000
```

Ключ указывается только локально. .env исключён из Git и недоступен по HTTP.
ai: true в health означает, что ключ настроен, а не успешную проверку доступа к OpenAI.
Без ключа или при ошибке AI используются явно помеченные демо-ответы. Для принудительного демо добавьте AI_MODE=demo в .env.

## Архитектура и данные

- server.js — единый HTTP-сервер: сайт, AI, API задач и откликов.
- api/server.js — совместимый старый вход в тот же сервер, отдельного бэкенда больше нет.
- api/tasks.js — черновики, публикация, редактирование и ручные решения.
- api/scoring.js — прозрачная формула рейтинга.
- app.js и tasks-ui.js — интерфейс с запросами к серверу.
- data/tasks.json — стартовые примеры. При первом запуске копируются в data/runtime/tasks.json.
- data/runtime/tasks.json — рабочее хранилище, исключено из Git. Черновики, задачи и предложения сохраняются после перезапуска.
- api/task-schema.json и docs/api-contract.md — формат ответа и маршруты.

Записи выполняются через временный файл и переименование; рассчитано на один процесс Node.js.
Для другого пути задайте EDUTASK_DATA_FILE. На хостинге нужен постоянный диск.
Старые данные localStorage не удаляются, но интерфейс больше не читает их: при необходимости перенесите свои старые карточки вручную.

## Рейтинг

Баллы фиксируются только после ручного подтверждения карточки. AI не назначает рейтинг.
Предварительный расчёт до подтверждения явно помечен в интерфейсе.

| Поле | Баллы | Проверка |
| --- | ---: | --- |
| Контекст | 20 | Минимум 30 символов |
| Материалы | 20 | Минимум 10 символов |
| Результат | 15 | Минимум 20 символов |
| Критерии | 15 | Минимум 2 непустых пункта |
| Ограничения | 10 | Непустой пункт или срок |
| Аудитория | 10 | Непустой пункт |
| Контакт и взаимодействие | 10 | Контакт от 5 символов и формат обратной связи |

Это простая проверка заполненности для MVP, а не оценка педагогического качества текста.
Уровни: 0–39 draft, 40–69 working, 70–89 ready, 90–100 priority.
Низкий рейтинг не запрещает публикацию или отклик. Каталог по умолчанию сортируется по рейтингу.
Оценка соответствия навыкам команды показывается отдельно и не заменяет рейтинг готовности.

## Демо за 5 минут

1. Создайте задачу: «Мне нужен интересный урок истории для школьников».
2. Проверьте предлагаемые AI ответы на три вопроса, исправьте их при необходимости и сформируйте карточку. Варианты с «Можно…» — предложения, а не установленные факты.
3. Добавьте результат, два критерия, контакт и формат обратной связи. Покажите рост предварительного рейтинга.
4. Подтвердите карточку галочкой и опубликуйте.
5. В каталоге переключите роль на «Студенческая команда». Откройте задачу и отправьте идею, план, срок и ссылку.
6. Переключитесь на «Преподаватель», снова откройте задачу и примите предложение.
7. Можно принять несколько команд; остальные отклики не отклоняются автоматически.
8. Откройте сайт в другом браузере или перезапустите сервер — задача и решения сохраняются.

Опубликованную карточку можно редактировать с новым подтверждением; рейтинг пересчитается.
Кнопка «Обновить каталог» получает актуальные данные из других браузеров.

## Проверки

```powershell
npm.cmd test
```

Тесты запускают отдельный сервер с временным хранилищем и демо-режимом. Проверяются перезапуск, низкий рейтинг, подтверждение, несколько откликов, несколько выбранных команд, некорректные запросы и ошибки AI. Настоящие запросы в OpenAI не выполняются.

Дополнительная проверка интерфейса: `npm.cmd run test:browser`. Нужны Node.js 22+ (WebSocket) и Chrome/Edge на Windows, либо путь к Chromium в EDUTASK_BROWSER. Проверяет создание, рейтинг, публикацию, отклик, принятие, редактирование и обновление страницы в отдельном профиле браузера.

## Границы MVP

Роли переключаются для демонстрации, серверной авторизации нет: используйте для командного демо с синтетическими данными. Перед публичным запуском нужны аккаунты и проверка прав на редактирование и выбор команд. Нет оплаты, видеозвонков, производственной БД и общего проектного трекера.
