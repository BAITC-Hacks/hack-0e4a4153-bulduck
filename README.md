# EduTask

Прототип платформы, которая превращает педагогическую потребность в понятную задачу для студенческой команды.

## Запуск

Нужен Node.js 18 или новее. Зависимости устанавливать не требуется.

```bash
node server.js
```

Откройте http://localhost:3000. Для настоящих AI-ответов создайте файл `.env` рядом с `server.js`:

```env
OPENAI_API_KEY=ваш_ключ
```

Перезапустите сервер после добавления ключа. При необходимости модель задаётся переменной `OPENAI_MODEL`; по умолчанию используется `gpt-4o-mini`. Ключ остаётся на сервере и не отправляется в браузер.

Без ключа сервер выдаёт детерминированные демо-ответы. Если открыть `index.html` напрямую без сервера, интерфейс использует локальные подсказки; для настоящего AI нужен запуск через localhost.

## Сценарий

1. Преподаватель описывает потребность и при желании улучшает текст.
2. Система задаёт до трёх уточняющих вопросов и сама предлагает ответы по описанию. Преподаватель проверяет и при необходимости исправляет их; ответы учитываются при создании карточки.
3. Преподаватель редактирует карточку и проверяет её на пробелы перед публикацией. Замечания не блокируют решение преподавателя.
4. Задача появляется в каталоге. Опубликованные задачи хранятся в `localStorage` текущего браузера.
5. Команда вводит навыки и доступный срок, получает ранжирование задач и объяснение совпадения.

В каталоге есть три примера. Они не являются опубликованными пользовательскими задачами. Подбор в демо-режиме основан на совпадениях слов, а с ключом использует AI. Для общего каталога между пользователями потребуется серверное хранилище.
