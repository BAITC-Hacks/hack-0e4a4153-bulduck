# EduTask — MVP для AI Sana

Интерактивный прототип платформы, которая превращает сырое описание педагогической потребности в структурированную задачу для студенческих команд.

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не нужны.

Backend запускается командой:

```bash
npm start
```

Проверка сервера: `GET http://localhost:3000/api/health`.

## Сквозной сценарий

1. Преподаватель вводит краткое описание задачи.
2. Интерфейс показывает уточняющие поля.
3. Система формирует редактируемую карточку задачи.
4. Задача публикуется в каталоге.

## Контракт Backend и Frontend

Структура карточки задачи описана в [api/task-schema.json](api/task-schema.json), а endpoints — в [docs/api-contract.md](docs/api-contract.md).

На первом этапе Backend реализует эти endpoints на mock-данных. Подключение AI выполняется после проверки сквозного сценария без внешнего API.

AI-функция сейчас представлена локальным демо-контрактом в `app.js`. Следующий шаг — заменить `generateCard()` на серверный вызов OpenAI или NVIDIA API, сохранив поля карточки и валидацию ответа.
